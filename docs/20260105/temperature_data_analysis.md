## 6. Q7 失败原因分析

### 问题
> "某客户设备近一周内发生过哪些类型的告警？**具体告警时间和恢复时间分别是什么？**"

### 模型生成的 SQL
```sql
SELECT e.EVENT_TYPE_NAME, e.EVENT_TIME, 
       e.ALARM_CLEAR_TIME AS recovery_time  -- ❌ 列不存在！
FROM event_history e ...
```

### 实际的 event_history 表结构
```
EVENT_TIME      ✅ 存在
ACK_TIME        ✅ 存在（确认时间）
ACTION_TIME     ✅ 存在（处理时间）
ALARM_CLEAR_TIME  ❌ 不存在！
RECOVER_TIME      ❌ 不存在！
CLEAR_TIME        ❌ 不存在！
```

### 结论
- **问题设计缺陷**：问的是"恢复时间"，但表中没有这个字段
- **模型幻觉**：模型"发明"了 `ALARM_CLEAR_TIME` 列
- **应对方案**：
  1. 修改问题，去掉"恢复时间"要求
  2. 或在 Schema 描述中明确说明"没有恢复时间字段"
