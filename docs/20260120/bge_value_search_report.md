## 关键改进：消除列名幻觉

### 改进前的提示格式
```
问题中提到的值在数据库中可能对应: 'cisco', 'down'
```
→ LLM 容易使用不存在的列名（如 `EVENT_VALUE`）

### 改进后的提示格式
```
问题中提到的实体在数据库中匹配到以下列值，请在 WHERE 条件中优先使用这些列名和值：
  device_status='down', STATE_NAME='Down', NAME='Node down'
注意：请检查这些列是否存在于你选择的表中，如果不存在请使用相关的替代列。
```
→ 明确告知列名，减少幻觉
