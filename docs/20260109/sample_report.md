### 关键洞察
在 `t_bz_config_customer` 表中，有 1523 名活跃且未被删除的客户。这表明当前平台上拥有一个相对稳定的客户群体，其中所有列出的客户都是有效的并且处于活跃状态。

2. 该数据截止至 2026-01-09，之后的数据变化不会反映在此报告中。

### 附录：使用的 SQL 查询
