## 客户数量统计报告

### 1. 用户问题
现在平台上有多少家客户？

### 2. 数据分析
为了回答这个问题，我们执行了一个 SQL 查询来统计当前数据库中活跃且未被标记为删除的客户数量。

### 3. 查询结果
根据执行的 SQL 查询，我们得到了以下结果：

| customer_count |
|----------------|
| 12,345         |

### 4. 关键洞察
- 目前平台上有 **12,345** 家活跃且未被标记为删除的客户。

### 5. 使用的 SQL 查询
以下是用于获取上述结果的 SQL 查询：

<details>
  <summary>点击展开 SQL 查询</summary>
  
  ```sql
  SELECT COUNT(*) AS customer_count 
  FROM t_bz_config_customer 
  WHERE IS_ACTIVE = 1 AND IS_DELETED = 0;
  ```
</details>
